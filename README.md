# 📋 โปรแกรมติดตามงาน (Work Tracker Web App)
**พัฒนาด้วย Google Apps Script + Google Sheets + Tailwind CSS + Telegram Bot Notify**

เว็บแอปพลิเคชันสำหรับบริหารจัดการและติดตามสถานะงานแยกตามไซต์งาน ออกแบบให้ทีมงานทุกคนสามารถเข้าถึง ดูภาพรวม และอัปเดตสถานะงานร่วมกันได้อย่างสะดวกรวดเร็ว ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## 🌟 ฟีเจอร์เด่นของระบบ

1. **การจัดการงานแยกตามไซต์งาน (Site-based Tracking)**:
   - กรองดูงานเฉพาะไซต์งานที่ต้องการ หรือดูภาพรวมทุกไซต์งานพร้อมกัน
   - เพิ่มไซต์งานใหม่ได้ทันทีจากฟอร์มสร้างงาน หรือจัดการผ่านเมนูตั้งค่า
   - ป้ายกำกับไซต์งาน (Site Badge) มีสีสันที่แยกแยะได้ชัดเจน

2. **กระดานงานคัมบัง (Interactive Kanban Board)**:
   - แบ่งเป็น 4 สถานะ: **รอดำเนินการ**, **กำลังดำเนินการ**, **รอตรวจสอบ**, **เสร็จสิ้น**
   - รองรับการลาก-วางการ์ด (Drag & Drop) เพื่อเปลี่ยนสถานะทันที
   - ปุ่มลูกศรลัดสำหรับเปลี่ยนสถานะงานในคลิกเดียว

3. **มุมมองตารางงาน (Table View)**:
   - สำหรับผู้ที่ชอบดูรายละเอียดแบบตาราง
   - มี Dropdown เปลี่ยนสถานะงานได้โดยตรงในแต่ละแถว
   - ตัวนับจำนวนงานทั้งหมดและระบบค้นหาแบบ Real-time

4. **ระบบแจ้งเตือนผ่าน Telegram Bot อัตโนมัติ**:
   - แจ้งเตือนเมื่อมี **งานใหม่** ถูกสร้างเข้ามาในระบบ
   - แจ้งเตือนเมื่อมีการ **เปลี่ยนสถานะงาน** (เช่น จากรอดำเนินการ ➡️ กำลังดำเนินการ)
   - ข้อความแจ้งเตือนระบุไซต์งาน, ชื่องาน, ผู้รับผิดชอบ, ระดับความสำคัญ, และกำหนดส่ง
   - มีปุ่มทดสอบส่งข้อความในหน้าตั้งค่า

5. **ระบบเข้าสู่ระบบด้วยรหัส PIN 6 หลักผ่าน Telegram (OTP Login)**:
   - ผู้ใช้พิมพ์ Username แล้วระบบจะสุ่มรหัส PIN 6 หลัก ส่งตรงเข้า Telegram ส่วนตัวทันที
   - รหัส PIN ใช้ได้ครั้งเดียว (One-Time PIN) มีอายุ 5 นาที และเปลี่ยนใหม่ทุกครั้งที่ล็อกอิน
   - มีระบบจำกัดจำนวนครั้งที่กรอกผิด (ไม่เกิน 3 ครั้ง) เพื่อความปลอดภัยสูงสุด
   - มีหน้าจอจัดการสมาชิก (Users) สำหรับ Admin กำหนด Username, ชื่อ และ Telegram Chat ID

6. **ระบบฐานข้อมูลอัตโนมัติ (Zero-Config Database)**:
   - หากเปิดใช้งานครั้งแรก ระบบจะสร้างชีต `Tasks`, `Settings`, และ `Users` พร้อมจัดฟอร์แมตหัวตารางและตัวอย่างข้อมูลให้อัตโนมัติ

## 🚀 ขั้นตอนการติดตั้งและ Deploy ผ่าน Clasp (CLI)

### ขั้นตอนที่ 1: ล็อกอิน Google Account บน Clasp
เปิด PowerShell หรือ Command Prompt ที่โฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
cmd.exe /c clasp login
```
*(เบราว์เซอร์จะเปิดขึ้นมาเพื่อให้ล็อกอินบัญชี Google ที่ต้องการ)*

> **หมายเหตุ**: ตรวจสอบให้แน่ใจว่าได้เปิดใช้งาน **Google Apps Script API** ในบัญชี Google แล้ว โดยไปที่ [https://script.google.com/home/usersettings](https://script.google.com/home/usersettings) และเปิดสวิตช์ **Google Apps Script API = On**

### ขั้นตอนที่ 2: สร้างโปรเจกต์ Google Apps Script ใหม่
รันคำสั่งเพื่อสร้างโปรเจกต์ใหม่ประเภท Web App:
```bash
cmd.exe /c clasp create --title "WorkTracker" --type standalone
```
คำสั่งนี้จะสร้างโปรเจกต์บน Google Drive และบันทึก `scriptId` ลงในไฟล์ `.clasp.json` ให้อัตโนมัติ

*(กรณีต้องการผูกกับ Google Sheet ที่มีอยู่แล้ว: ให้เปิด Google Sheet > Extensions > Apps Script แล้วคัดลอก Script ID จาก Project Settings มาวางใน `.clasp.json`)*

### ขั้นตอนที่ 3: Push โค้ดขึ้น Google Apps Script
```bash
cmd.exe /c clasp push
```
กด `y` ยืนยันการเขียนทับ manifest file

### ขั้นตอนที่ 4: เปิดโปรเจกต์บนเว็บ และสร้าง Deployment (Web App URL)
1. รันคำสั่งเพื่อเปิดหน้าโปรเจกต์:
   ```bash
   cmd.exe /c clasp open-script
   ```
2. ที่มุมบนขวา คลิกปุ่ม **Deploy (ทำให้ใช้งานได้)** ➡️ เลือก **New deployment (การนำไปใช้งานใหม่)**
3. คลิกไอคอนฟันเฟือง ⚙️ ด้านซ้าย เลือกประเภท **Web app (เว็บแอป)**
4. ตั้งค่าดังนี้:
   - **Description**: `Work Tracker v1.0`
   - **Execute as (ดำเนินการในฐานะ)**: `Me (ฉัน / เจ้าของบัญชี)`
   - **Who has access (ผู้มีสิทธิ์เข้าถึง)**: `Anyone (ทุกคน)` *(เพื่อให้ทุกคนในทีมเข้าใช้งานได้โดยตรง)*
5. คลิก **Deploy** ➡️ จะได้รับลิงก์ **Web App URL** สำหรับส่งให้ทุกคนในทีมใช้งาน

## 🤖 วิธีการตั้งค่า Telegram Bot แจ้งเตือน

### 1. การสร้าง Telegram Bot เพื่อรับ Bot Token
1. เปิดแอป Telegram แล้วค้นหาบัญชี **`@BotFather`**
2. พิมพ์คำสั่ง `/newbot`
3. ตั้งชื่อบอท (เช่น `Work Tracker Bot`) และตั้งชื่อ Username ของบอท (ต้องลงท้ายด้วย `bot` เช่น `MyWorkTracker_bot`)
4. บอทจะให้ **HTTP API Token** (รูปแบบเช่น `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`) ให้คัดลอกเก็บไว้

### 2. การหา Telegram Chat ID
- **กรณีแจ้งเตือนเข้าแชตส่วนตัว**:
  1. ค้นหาบอท **`@userinfobot`** บน Telegram แล้วกด `/start`
  2. บอทจะแจ้งหมายเลข `Id` ของคุณ (เช่น `987654321`)
  3. ไปที่บอทที่คุณสร้างขึ้นมาในข้อ 1 แล้วกดปุ่ม **Start** หนึ่งครั้งเพื่อให้บอทส่งข้อความหาคุณได้
- **กรณีแจ้งเตือนเข้า Telegram Group ของทีม**:
  1. ดึงบอทที่คุณสร้างเข้ากลุ่ม Telegram ของทีม
  2. ตั้งค่าให้บอทเป็น Admin ของกลุ่ม (หรือส่งข้อความในกลุ่ม 1 ข้อความ)
  3. ดู Group Chat ID (โดยทั่วไปจะเป็นเลขติดลบ เช่น `-1001234567890`)

### 3. กรอกลงในหน้าเว็บ Work Tracker
1. เปิดเว็บแอปพลิเคชัน Work Tracker
2. คลิกปุ่ม **⚙️ ตั้งค่า** ที่มุมขวาบน
3. วาง **Telegram Bot Token** และ **Telegram Chat ID**
4. คลิกปุ่ม **"ทดสอบส่งข้อความไปยัง Telegram"** หากข้อความเด้งเข้า Telegram แสดงว่าเชื่อมต่อสำเร็จ
5. คลิก **"บันทึกการตั้งค่า"**

### 4. การผูก Telegram Chat ID ให้สมาชิกเพื่อรับรหัส PIN เข้าสู่ระบบ
1. ให้สมาชิกทุกคนเข้าไปที่บอท Telegram ที่สร้างไว้ แล้วกดปุ่ม **Start** 1 ครั้ง (เพื่อให้บอทมีสิทธิ์ส่งรหัสหาได้)
2. สมาชิกขอหมายเลข `Id` ส่วนตัวของตนเองจากบอท **`@userinfobot`**
3. ผู้ดูแลระบบสามารถใส่หมายเลข Chat ID ให้สมาชิกได้ 2 วิธี:
   - **ผ่านหน้าเว็บ**: เข้าเมนู **⚙️ ตั้งค่า** ➡️ แท็บ **"จัดการสมาชิก (Users)"** ➡️ กดแก้ไขหรือเพิ่มสมาชิกพร้อมระบุ Chat ID
   - **ผ่าน Google Sheet**: เปิด Google Sheet ➡️ เลือกแท็บแผ่นงาน **`Users`** ➡️ กรอกหมายเลขในคอลัมน์ `TelegramChatId` ให้ตรงกับ Username นั้นๆ ได้ทันที
