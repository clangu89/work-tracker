  3. รอจนขึ้น [SUCCESS] Installation v2.0 แล้วกดปุ่มใดๆ เพื่อปิด
  4. กลับมาที่หน้าเว็บนี้ แล้วกดปุ่ม "Remote" ได้ทันที!
