ตัวเชื่อมต่อ 1-Click & แก้ปัญหา Copy ไฟล์

ระบบ 1-Click Zero-Prompt (v2.0) ช่วยให้คุณกดปุ่ม "Remote" บนหน้าเว็บ แล้วเปิด Windows Remote Desktop (mstsc.exe) ล็อกอินรหัสผ่านให้อัตโนมัติ พร้อมเปิดใช้งาน Copy-Paste ข้อความและไฟล์ทุกชนิด ทันที!

🔄 สำหรับผู้ที่เคยติดตั้งเวอร์ชันเก่าไว้แล้ว:
กดดาวน์โหลดตัวติดตั้ง v2.0 ด้านล่างไปดับเบิลคลิกทับอีก 1 ครั้ง เพื่อเปิดระบบ Copy ไฟล์และแชร์ไดรฟ์ (ปลอดภัย 100% รันในระดับ Current User ไม่ต้องใช้สิทธิ์ Admin)
ขั้นตอนการติดตั้ง / อัปเดต:
  1. กดปุ่ม "ดาวน์โหลดตัวติดตั้ง v2.0 (.bat)" ด้านล่าง
  2. ดับเบิลคลิกเปิดไฟล์ install-rdp-protocol.bat
  3. รอจนขึ้น [SUCCESS] Installation v2.0 แล้วกดปุ่มใดๆ เพื่อปิด
  4. กลับมาที่หน้าเว็บนี้ แล้วกดปุ่ม "Remote" ได้ทันที!
* ปลอดภัย 100% ไม่ดัดแปลงไฟล์ระบบของเครื่อง

2️⃣ ซ่อมฝั่งเครื่องปลายทาง (กรณี Copy ไม่ได้ทั้งข้อความและไฟล์)

  1. ในหน้าจอเครื่องรีโมต คลิกขวาปุ่ม Start เลือก Run (หรือเปิดหน้าต่าง CMD ทิ้งไว้)
  2. สลับกลับมากดปุ่มสีส้มด้านล่างนี้ ระบบจะพิมพ์คำสั่งซ่อมเข้าหน้ารีโมตให้อัตโนมัติ (รองรับทั้งคีย์บอร์ดไทยและอังกฤษ)
